# USELESS POETRY｜无用诗歌生成器

AI Passport 独立离线 ESP-IDF 5.5.3 玩法：ESP32-C3、8 MB Flash、无 PSRAM、
240×320 竖屏。开发隔离在 `feature/useless-poetry` 分支，保留 BSP、原演示源码和
默认分区，构建入口改为 `poetry_app.c`，不进入基础测试菜单。
不启动无线、音频、麦克风或云服务，不需要 API 密钥。

## 玩法和按键

四种人格可手动选择，拥有独立原创语料：ABSURD 荒诞诗人（日常物件悄悄罢工）、
MELANCHOLY 忧郁诗人（温柔忧郁与幽默落点）、CORPORATE 办公室诗人（办公室仪式）、
COSMIC 宇宙诗人（宇宙与生活小事）。视觉分别为暖纸与歪斜墨迹、蓝灰雨线、
绿色办公横线、深蓝星点。全部标签使用 16 px 应用中文字体，每首诗 2–4 行。

| 页面 | 短按上 | 短按下 | 短按确定 |
| --- | --- | --- | --- |
| 主页 | 上一个人格 | 下一个人格 | 生成 |
| 诗歌页 | 上一个人格/主页 | 下一个人格/主页 | 收藏或取消收藏 |
| 历史 | 上一首 | 下一首 | 收藏或取消收藏 |
| 废纸篓 | 上一个收藏 | 下一个收藏 | 取消收藏 |
| 等待 | 忽略 | 忽略 | 忽略 |

等待之外，长按上进入历史，长按下进入废纸篓，长按确定回主页。
列表到边界停止，人格循环切换。BSP 单键长按阈值为 500 ms，长按松手不触发短按。
ADC 每 10 ms 采样，三个去抖周期合计 30 ms。适配层使用已去抖的
PRESS/LONG/RELEASE，快速连按逐次处理，不因 BSP 双击分类丢失动作。
组件连击状态不产生 LONG 事件时，应用任务也按单调时钟识别长按。
等待中开始的按键即使在诗歌出现后松手也被忽略。共享定时器回调只将带时间戳的
事件入队，队列溢出时等待全部按键松开；启动按住的键也屏蔽至松手。
闲置 30 秒背光降至 10%，60 秒关闭；黑屏后首键只恢复背光，不执行操作。
不自动深睡，电量读取失败时显示 `--%`。

## 生成、稀有度和动画

16 个人格/稀有度语料池，每池四个开头、两行可选中段、四个结尾，围绕同一意象。
六个变体位产生每池 64 种、总计 1024 种组合。这是策划语料的离线组合，
不是板上大语言模型。可能重复；有限语料可以逐一校验文字与排版。

| 稀有度 | 概率 | 抽签值 | 内容与显示 |
| --- | --- | --- | --- |
| 普通废话 | 65% | 0–64 | 日常小荒诞，人格强调色 |
| 优质废话 | 25% | 65–89 | 抒情意象，明确稀有度标签 |
| 哲学事故 | 9% | 90–98 | 存在、证据、缺席，赭色标签 |
| 宇宙级废话 | 1% | 99 | 宇宙尺度的生活事故，金色或赭色标签 |

对 `esp_random()` 拒绝采样，消除取模偏差；稀有度抽签与诗歌变体独立。
无线服务关闭，随机仅用于娱乐，不作密码学保证。概率是独立抽取概率，
不是配额，也不保证 100 次内必定出现宇宙级。

等待画面在持有 BSP LVGL 锁时安装，之后由 `esp_timer_get_time()` 单调时钟
计时 2000 ms，绝不提前完成。25 ms 应用循环及屏幕调度带来物理误差；真机验收
目标为等待首次可见至诗歌出现 2.00–2.15 秒。等待唯一文案为
「正在提取无意义」，没有圆圈加载器、进度条或其他运算文案。
诗歌先显示，再在 LVGL 锁外写历史记录。

原创 MIT 授权 SVG 转为三个 Flash 常驻 RGB565+A8 图层，共 50,520 字节。
水獭仰躺，身体、双手和冰饮保持固定，仅一只后脚在 1600 ms 周期内上下各移动
两像素，另一只脚固定。整体在等待中横移六像素，伴随轻微半透明水波。
不分配整屏画布、逐帧精灵序列或动画定时器。长期复用 LVGL 对象树；
单个应用任务拥有状态，UI 调用持有 BSP LVGL 锁。

## 持久化约定

历史最新优先保存 32 首，废纸篓独立保存 24 首。历史淘汰不删除收藏。
收藏满时拒绝添加，不覆盖原收藏。空、满、错误状态明确显示。
存储成功才确认收藏；失败恢复此前内存收藏状态。未保存历史仍在 RAM 中可读并提示。

分区不变：NVS `0x9000/0x6000`、PHY `0xF000/0x1000`、factory
`0x10000/0x7F0000`。仅使用 `useless_poetry` 命名空间的 `records_v1` 键。
696 字节快照包含标识、语料版本、下一编号、选定人格、数量、12 字节小端记录和
CRC32。记录保存编号、变体、人格和稀有度；**语料 v1 必须不变**，保证原诗重现。
历史与收藏一起序列化，使用 NVS blob 替换与 commit 获得平台断电行为，仍需硬件验收。
未知版本、CRC 错误、非法数量/编号及冲突记录会停写并保留原 blob。
错误恢复从不擦除 NVS；未来语料修改需要明确迁移与版本策略。

## 重现和验证

激活已有 ESP-IDF 5.5.3 环境，再执行：

```sh
./tools/validate.sh --static
./tools/validate.sh --firmware
./tools/validate.sh
```

静态测试覆盖所有组合、稀有度边界、等待期限、按键分类、列表边界、容量、淘汰、
序列化往返、快照每字节单字节损坏、编号溢出和资源来源。
字符/哈希检查只需 Python 标准库。固件检查从版本管理的默认配置隔离构建，
验证分区 MD5、偏移、边界、合并字节及内容寻址包中配套 ELF。
NVS 故障注入覆盖初始化、打开、过大/损坏读取、写入/提交失败、句柄重开、
重启恢复，测试适配层不提供擦除 API。

依赖下载后，测试实际锁定的 LVGL 9.5.0 渲染器：

```sh
cmake -S tests/poetry_lvgl -B work/lvgl-test -G Ninja
cmake --build work/lvgl-test -j 6
mkdir -p work/preview
work/lvgl-test/test_poetry_ui work/preview
```

使用固件相同的 24 KiB 池和单个 40 行 RGB565 绘图缓冲，检查实际字形描述符
（包括故意缺失字符）、控件字体、所有诗歌文本边界、等待唯一文案、80 个动画帧、
空/错误页面和 300 次切页。可选 PPM 截图来自真实应用 UI 与 BSP 圆角遮罩，
不是浏览器模型。启动日志记录空闲内部堆及最大连续块，每 30 秒记录堆及任务
栈余量，真实板上值仍未验证。
资源来源、授权和再生成参见[资源说明](../../assets/README.zh_CN.md)。

## 确认后安装

使用验证通过的 `build/FoloToy-AI-Passport-full.bin`，或交付的同一文件
`USELESS-POETRY-full.bin`，通过 AI Passport 官方工具的自定义固件流程安装。
选择 ESP32-C3、8 MB，完整镜像从 `0x0` 写入，不可将仅应用镜像写到 `0x0`。
先核对交付报告中的 SHA-256。官方工具界面随版本变化，以其流程文档为准。

合并刷写可能重置 NVS、历史和收藏。如需兼容升级保留数据，先核对分区不变，
使用**同一验证包中的**应用镜像写到 `0x10000`。不使用其他重编译文件，不整片擦除。
明确批准后也可在本地执行：

```sh
python -m esptool --chip esp32c3 --port PORT --baud 460800 \
  write_flash --flash_size 8MB 0x0 USELESS-POETRY-full.bin
```

本次实现不包括刷机、合并 main、正式发布或官方目录上架。
PR 待用户确认与硬件验收。
